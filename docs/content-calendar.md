## 并行生产节奏

### 型号页（36 → 200+）

- 管线已就绪：`scripts/import-model-records.mjs` 从 CSV 批量导入型号记录（模板见 `docs/model-records-import.template.csv`）。
- 数据来源：供应商目录导出、自有库存表、hydparts.com 等关联站点数据。
- 节奏：每月1次导入，每批50条；导入后跑 `npm run verify`。
- 前置：每条记录必须有公开来源URL（品牌、型号、系列、产品类型、来源站点），无来源数据不导入。

### 博客/指南（33 → 81+）

- 每月4篇（按上方日历），每篇600-1200词，含1-2个表格。
- 优先顺序：A级（第1-3月）→ B级（第4-6月）→ C级（第7-12月）。
- 每篇完成后更新 `outputs/content-calendar.csv` 状态为 `published`。

### 外链建设（见 `docs/link-building-plan.md`）

- 每月1个批次：目录注册、LinkedIn、问答、视频。

## 关键词与流量预期

- 内容日历主题对应421词研究中的信息型与采购型词（volume 10-720）。
- 型号页对应型号长尾词（零工具量但高询盘转化）。
- 12个月后：233页 → 380+页，其中型号页200+。
- 配合外链：期望第6个月起询盘进入20-50/月，第12-18个月冲击100/月。
