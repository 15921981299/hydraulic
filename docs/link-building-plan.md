# 外链建设计划

> 新域名零外链是排名天花板。按季度分批建设，全部为可执行的白帽动作。

## 优先级A：行业目录（第1个月起）

| 目录 | 类型 | 动作 |
| --- | --- | --- |
| ThomasNet | B2B工业目录 | 注册公司页，提交产品类别 |
| Europages | 欧洲B2B目录 | 注册并完善公司简介 |
| Kompass | 全球B2B目录 | 注册公司档案 |
| Made-in-China / Alibaba | 中国供应商目录 | 公司页链接回独立站 |
| Hydraulics & Pneumatics 目录 | 行业垂直 | 提交供应商条目 |

## 优先级B：内容型外链（第2个月起，配合内容日历）

| 渠道 | 动作 |
| --- | --- |
| LinkedIn 公司页 | 每篇新内容发布后同步摘要+链接 |
| YouTube | 每季度1个拆解/检验视频，描述栏链接 |
| 行业论坛（Hydrostat、Reddit r/Hydraulics等） | 真实答疑时自然提及（避免垃圾链接） |
| 供应商/客户站 | 合作页面互相链接（仅在真实合作后） |
| 旧站 hydparts.com | 若确认为自有：迁移301（见 migration-plan.md） |

## 优先级C：数字PR（第4个月起）

- 行业媒体投稿（Machine Design、Fluid Power World 等）的实用技术文章
- HARO/Connectively 类记者问答（被引用获得权威外链）

## 每月检查

- 新增外链域名数（GSC 外链报告 + Ahrefs 免费版）
- 权威域名增长曲线：第3个月 ≥ 5，第6个月 ≥ 15，第12个月 ≥ 40
- 外链锚文本多样化（品牌词+产品词混合，避免过度优化）
